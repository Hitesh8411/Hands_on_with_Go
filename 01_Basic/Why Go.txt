# Go (Golang) Notes — Basics of Go

# What is Go?

Go (also called Golang) is an open-source programming language developed by Google.

It is designed to be:

* Simple
* Fast
* Efficient
* Scalable
* Easy for concurrent programming

Go is mainly used for:

* Backend development
* Cloud computing
* APIs
* DevOps tools
* Distributed systems
* Networking applications

---

# Who Developed Go?

Go was developed by engineers at Google:

* Robert Griesemer
* Rob Pike
* Ken Thompson

---

# When Was Go Developed?

* Go development started in 2007
* Officially announced in 2009
* Stable release Go 1.0 came in 2012

Official Website:

[Go Official Website](https://go.dev/?utm_source=chatgpt.com)

---

# Why Was Go Created?

Before Go, developers faced problems with languages like:

* Slow compilation
* Complex syntax
* Difficult concurrency
* Large codebases becoming hard to manage

Google needed a language that was:

* Fast like C/C++
* Simple like Python
* Concurrent like Erlang
* Efficient for modern servers

So Go was created.

---

# Why is Go Popular?

## 1. Simple Syntax

Go syntax is easy to read and learn.

Example:

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello World")
}
```

---

## 2. Very Fast

Go is a compiled language.

It converts code directly into machine code.

So execution is very fast.

---

## 3. Excellent Concurrency

Go supports concurrency using:

* Goroutines
* Channels

This helps in building scalable applications.

---

## 4. Easy Deployment

Go creates a single executable binary.

No need to install many dependencies.

---

## 5. Strong Cloud Support

# Features of Go

## 1. Compiled Language

Go converts source code into binary executable files.

---

## 2. Statically Typed

Variable types are checked during compilation.

Example:

```go
var age int = 22
```

---

## 3. Garbage Collection

Go automatically manages memory.

Developer does not need manual memory handling.

---

## 4. Goroutines

Lightweight threads for concurrency.

Example:

```go
go task()
```

---

## 5. Channels

Used for communication between goroutines.

Example:

```go
ch := make(chan int)
```

---

## 6. Cross Platform

Go programs run on:

* Windows
* Linux
* macOS

# Basic Structure of Go Program

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello Go")
}
```

## Explanation

| Part          | Meaning        |
| ------------- | -------------- |
| package main  | Main package   |
| import        | Import package |
| func main()   | Entry point    |
| fmt.Println() | Print output   |
